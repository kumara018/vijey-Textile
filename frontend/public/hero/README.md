# Opening photographs

Images placed here appear in the homepage opening, in the order listed in
`src/lib/heroGarments.ts`. Adding a file here does nothing on its own — it has
to be listed there too, so the order is deliberate rather than alphabetical.

**Shape:** portrait, roughly 3:4. That is the shape of the frame, so a 3:4
photograph fills it with nothing cropped. A landscape photograph will be
cropped to fit, which is the problem this frame was built to solve.

**Subject:** the garment whole — on a hanger or laid flat, with room around it.
Garments rather than people, which is the reason this folder is curated by hand
instead of the opening choosing for itself.

**Size:** about 1200px on the long edge. Larger is bandwidth a customer on a
phone pays for and cannot see.
